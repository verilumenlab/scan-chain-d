Architectural Design Principles:
  • Decoupled Diagnostics Engine: Core algorithms in src/ execute independently of any UI layer, callable via CLI (export_outputs.py), Streamlit, or FastAPI adapters.
  • Vectorized Math Engine: Avoids Python row-iteration bottlenecks by using vectorized NumPy/Pandas array operations, delivering ~39x speedup over standard DataFrame applies.
  • Zero Artificial Confidence Inflation: Adheres strictly to production honesty. Suspected breaks are flagged as CERTAIN only when soft agreement is $\ge 70\%$ across $\ge 2$ patterns. Low confidence is reported truthfully without artificial floors.

SCD-FR-001

Failing Scan Chain Identification Agent

High-Throughput ATE Log Ingestion & Failing Chain Inventory
KPI: failing_chains Parquet Warm Cache Multiprocessing
Core Objective & Ingestion Architecture

Ingests massive multi-gigabyte production ATE pattern failure logs across Tessent and compact inline multi-channel formats. Expands compressed cycle representations and catalogs every failing chain.

  • Dual Format Parser: Native support for traditional Tessent logs and compact inline logs with PATTERN_METRICS blocks.
  • Run-Length Cycle Expansion: Automatically expands X@{n} compressed non-failing/masked cycles into absolute physical shift cycles.
  • GIL Bypass: Utilizes ProcessPoolExecutor to parse 90+ files concurrently across all CPU cores.
Algorithms, Cache & Deliverables
Cache_Key = SHA-1(FilePath + MTime + FileSizeBytes)
Serialized to: data/cache/logs_<hash>.parquet
  • Warm Parquet Cache: Reduces subsequent reload times from 10+ minutes to < 0.2 seconds.
  • Deliverable: output/SCD-FR-001_failing_scan_chains.json
  • Source Modules: src/parser.py src/disk_cache.py specs/FR-001.md
SCD-FR-002

Suspected Failing Cell Localization Agent

Vectorized Flop-to-Cell Mapping with Dual-Stage Float Parity
KPI: suspected_cells Vectorized Math Float Parity 100%
Objective & Vectorized Localization

Translates raw tester cycle failures into exact physical scan cell instances within the silicon hierarchy, resolving fractional clocking ambiguities and attaching ML root causes.

  • Vectorized Math Engine: Replaces row-by-row iteration with native Pandas array operations, accelerating localization by ~39x.
  • Dual-Stage Float Rounding: Neutralizes IEEE-754 floating-point inaccuracies using round(round(x, 10), 3), achieving 100% parity with golden diagnostics.
Mapping Formulas & Deliverables
bit_position = shift_cycle - cycle_offset
offset_from_scan_in = chain_length - 1 - bit_position
  • Defect Annotation: Attaches Random Forest predicted root cause (Stuck-At, Bridge, Timing Setup/Hold) and calibrated confidence score.
  • Deliverable: output/SCD-FR-002_suspected_failing_cells.json
  • Source Modules: src/locate_cells.py src/ml_pipeline.py specs/FR-002.md

STIL ScanStructures, EDT Channels & Connectivity Modeling

Objective & Structural Parsing

Reconstructs the full DFT scan topology from IEEE 1450 STIL design files and hardware topology markdown specifications to establish physical and logical connectivity.

SCD-FR-004

Scan Chain Failure Ranking & Pareto Analysis Agent

Deterministic Dense Ranking with 80/20 Cumulative Pareto Cutoff
KPI: ranked_chains Pareto 80/20 Dense Rank
Objective & Prioritization

Ranks failing scan chains by failure frequency and unique failing pattern counts to isolate the "vital few" chains causing the vast majority of yield loss.

  • Dense Ranking: Native Series.rank(method="dense", ascending=False) ensures deterministic, monotonic rank assignment without gaps.
  • Pareto Frontier: Calculates cumulative failure percentages to immediately identify the minimal subset of chains responsible for 80% of silicon fails.
Pareto Math & Deliverables
Pareto_Pct(k) = ( ∑_{i=1..k} Fails_i / Total_Fails ) × 100%
Vital_Few = { c | Pareto_Pct(c) ≤ 80.0% }
  • Interactive Pareto Chart: Powers dashboard Pareto dual-axis bar and cumulative percentage line charts.
  • Deliverable: output/SCD-FR-004_chain_failure_ranking.json
  • Source Modules: src/chain_ranking.py specs/FR-004.md
SCD-FR-005

Physical & Timing Variable Correlation Analysis Agent

Pearson Multivariate Correlation & AI Severity Profiling
KPI: failure_correlations Pearson Matrix AI Severity
Objective & Physical Parameters

Uncovers the physical drivers behind scan chain failures by correlating failure density against electrical and spatial parameters across the entire wafer population.

  • Physical Variables Analyzed: Dynamic IR drop ($\Delta V$), operating junction temperature ($^\circ\text{C}$), setup/hold timing slack, and wafer radial positions $(X_{die}, Y_{die})$.
  • Categorical Profiles: Identifies if failures concentrate within specific functional regions (e.g. Core Logic vs. SerDes PHY vs. Memory Periphery).
Pearson Math & Severity
r = Cov(Fails, Feature) / ( σ_fails · σ_feature )
Severity = High if |r| ≥ 0.70 else Medium if |r| ≥ 0.40 else Low
  • Population Deviation: Quantifies how anomalous each chain's operating envelope is relative to the healthy die distribution.
  • Deliverable: output/SCD-FR-005_failure_correlation.json
  • Source Modules: src/correlation_analysis.py specs/FR-005.md
SCD-FR-006

Exact Scan Chain Break Localization Agent

Consensus First-Mismatch Scanner with Production CERTAIN Gating
KPI: chain_breaks Trailing-X Care Bits Zero Fake Floors
Objective & Hard Open Detection

Pinpoints the exact flip-flop where a scan chain shift path open or stuck-at break prevents data shift, using consensus bitstream mismatch analysis.

  • Consensus Mismatch: Detects the first divergence bit between expected and actual test vectors across patterns, preventing single-pattern noise skew.
  • Trailing-X Care-Bit Extraction: Dynamically identifies the true active scan-out boundary by filtering trailing non-care masking bits (X).
Honesty Gates & Formula
SoftAgreement = Fraction(Patterns with mismatch in [bit-1, bit+1])
Status = CERTAIN if (SoftAgreement ≥ 70% and Patterns ≥ 2) else UNCERTAIN
  • Production Honesty: When evidence is insufficient, marks status as UNCERTAIN while still exposing candidate bits for manual PFA review.
  • Deliverable: output/SCD-FR-006_scan_chain_breaks.json
  • Source Modules: src/chain_breaks.py specs/FR-006.md
SCD-FR-007

Shift vs. Capture Defect Classification Agent

Hierarchical Root-Cause Decision Cascade & Anomaly Scoring
KPI: shift_capture IsolationForest Timing Slack Signs
Objective & Classification Cascade

Disambiguates serial scan-shift transport defects (chain integrity/open) from parallel at-speed functional capture defects (logic paths, voltage droop, timing slacks).

  • Shift Path Defect: Triggered when a validated FR-006 break or systematic bitstream shift failure signature is present.
  • Capture Timing Defect: Triggered when the shift path is fully functional, but negative setup slack ($t_{setup} < 0$) or hold slack ($t_{hold} < 0$) is observed.
  • Capture Logic / Anomaly: Combinational point defects isolated via IsolationForest anomaly scoring.
Decision Logic & Deliverables
IF has_valid_break(chain) ➔ SHIFT_DEFECT
ELSE IF setup_slack < 0 or hold_slack < 0 ➔ CAPTURE_TIMING
ELSE IF is_anomaly ➔ CAPTURE_ANOMALY ELSE CAPTURE_LOGIC
  • PFA Direction: Directs lab engineers whether to inspect scan chain clock/data lines or combinational gate cones.
  • Deliverable: output/SCD-FR-007_shift_capture_diagnosis.json
  • Source Modules: src/export_outputs.py src/ml_pipeline.py specs/FR-007.md

Silicon Physical XY Debug Coordinate Localization Agent

Die-Local (μm) & Wafer (mm) Probing Coordinate Transformation
KPI: debug_locations PFA Lab Ready FIB / SEM Coordinates
Objective & Physical Localization

Bridges the gap between logical register design hierarchies and physical silicon geometry, providing micrometer-accurate coordinates for FIB de-processing and laser voltage probing.

SCD-FR-010

Multi-Evidence Diagnosis Confidence & PFA Scoring Agent

Calibrated Evidence Scoring with Fail-Weighted Top-1 KPI Aggregate
KPI: avg_confidence PFA Feedback Retrain Zero Artificial Floor
Objective & Multi-Evidence Math

Replaces arbitrary diagnostic guesses with an empirically calibrated confidence score combining 4 observational evidence dimensions with a PFA-trained logistic model.

  • Multi-Factor Observational Evidence: $$S_{evidence} = 0.40 \cdot \text{Dom}_{rel} + 0.25 \cdot \text{Corrob}_{pat} + 0.20 \cdot \text{Share}_{obs} + 0.15 \cdot \text{Consist}_{type}$$
  • Zero-Dependency ML PFA Blending: $$\text{Confidence} = 0.55 \cdot S_{evidence} + 0.45 \cdot P_{ML}(\text{True Defect})$$
System Trust KPI & Model Lifecycle
Aggregate_Trust = ∑(Fails_c · max_cell(Conf_cell)) / ∑(Fails_c)
Auto-Retrain Threshold = 25 PFA Engineer Feedback Labels
  • Fail-Weighted Top-1 Metric: Avoids dilute long tails of weak candidates by aggregating only the highest-confidence suspect per failing chain.
  • Closed-Loop Feedback: Retrains the PFA classifier automatically when $\ge 25$ lab review labels accumulate in review_queue.py.
  • Source Modules: src/confidence_score.py src/model_lifecycle.py specs/FR-010.md
